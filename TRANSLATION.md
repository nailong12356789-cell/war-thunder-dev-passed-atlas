# Translation status / 双语维护说明

This is an independent, bilingual **Chinese / English** War Thunder fan atlas. The source data and the interface should not be confused with official game content.

## Current support
- Language switch: **中文 / English** (browser language detected initially; a locally saved preference can override it).
- Nation names, filters, categories, status labels and navigation are translated.
- Chinese and English names/aliases can both be used for searching where aliases exist.
- English vehicle-analysis text is a **conservative auto-generated summary**, not a full professional translation of each original Chinese note.
- Expand **Original analysis (Chinese)** on a card to check the source technical rationale.
- If JavaScript is blocked (e.g. some iOS file previews), the standalone HTML has a static Chinese fallback catalog.

## Contributing translations
1. Verify model designations and national variants using reputable source material.
2. Make no unsupported claims about missiles, armor, thermal sights, penetration, or in-game BR.
3. Label projected RB estimates as **unofficial**.
4. Distinguish “passed to developers” from “implemented” and from “scheduled for implementation”.
5. Include the reference URL and check date when proposing corrections.

## 中文说明
- 界面和搜索支持中英双语；技术分析仍以原始中文为准。
- 英文摘要不等于准确逐句翻译，不能把推测写成已证实的游戏配置。
- 如果发现国家、型号或子线归属错误，请提供官方论坛、War Thunder Wiki 等来源链接，并创建 Issue。
