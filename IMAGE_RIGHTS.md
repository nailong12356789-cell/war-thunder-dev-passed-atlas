# Image rights / 图片版权与许可

**Current public release:** the GitHub repository does not bundle the image binaries from the original offline atlas. Vehicle records may contain external photo source links, but their presence does **not** establish that a photo can be redistributed or re-embedded.

**当前公开版本：** 仓库不打包原始图鉴中嵌入的第三方图片。数据里保留的外部图片链接仅供溯源，**不意味着已获得转载、下载或重新分发许可**。

## When an image can be included / 收录条件

Before adding an image file or `data:` embedded image to `index.html`, record all of the following:

1. Vehicle record ID and exact variant shown in the photo.
2. Original source URL (prefer the creator's original posting, not an image mirror).
3. Photographer/creator and rights holder, or a justified public-domain determination.
4. Specific permission/license with its authoritative URL or written authorization.
5. Required attribution wording and a source-credit link.
6. Modification requirements, including whether crop/resize/re-encoding is permitted.
7. Verification date and a brief note confirming the image actually depicts the intended vehicle.

Where a license cannot be verified, **keep the external source link only**. Do not infer permission from an image being visible on a forum, wiki, social network, search engine, or video screenshot. Do not use classified, confidential, unlawfully obtained, or leaked material.

## Maintainer review checklist / 维护审查

- [ ] Identify exact vehicle and image provenance
- [ ] Confirm redistribution rights (and derivative rights if editing)
- [ ] Save required author and license attribution
- [ ] Check image size/format for iPhone and Windows offline performance
- [ ] Check the card displays the correct photograph and no placeholder flag
- [ ] Verify the HTML remains usable offline and the repository license remains correctly scoped

The MIT license in `LICENSE` covers original presentation code identified in the README; it **does not apply to third-party photographs, game assets, or external links**.
